# Repository Map

## Принципы структуры

Публичные пути описывают содержание проекта и не требуют знания внутренних шифров учебного курса.

```text
practice/<project>/<level>
assignments/<area>/<subject-or-project>
```

### `practice/`

Учебная практика. Для каждого проекта сохранена эволюция решения:

- `base` — исходное выполнение;
- `plus` — расширение;
- `max` — наиболее полная версия.

| Проект | Путь |
|---|---|
| Birthdate App | `practice/birthdate-app/` |
| Counter App | `practice/counter-app/` |
| Greeting App | `practice/greeting-app/` |
| Calculator | `practice/calculator/` |
| Project Review | `practice/project-review/` |

| Направление | Путь |
|---|---|

## Именование новых работ

Для следующих дисциплин используйте человекочитаемый kebab-case и помещайте работу в одно из четырёх направлений: `programming`, `systems`, `architecture`, `design`. Новый внутренний шифр института не должен становиться именем публичного каталога.
