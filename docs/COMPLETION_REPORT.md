## Подготовлено, но требует внешнего подтверждения

- Java Fundamentals, тема 1: установка и настройки IntelliJ IDEA на устройстве студента не подтверждаются Git-репозиторием; подготовлены инструкция и локальная проверка JDK.

- Networking: Cisco IOS configs/addressing/verification готовы; `.gns3`, реальные `show`/`ping`/captures требуют локального GNS3 и легального IOS image.
- UI/UX: локальные boards, research/test plans, handoff и recording materials готовы; реальные участники, Google Form, Figma Prototype/Dev Mode и video URL должны создаваться во внешних сервисах.
- Git documentation: remote/clone/branch воспроизводятся локально; реальные URL вновь созданных GitHub и Bitbucket repositories требуют аккаунтов владельца.

## Важные технические улучшения

- GRE lab использует требуемый треугольник из трёх туннелей, Loopback и OSPF overlay.
- React forms homework использует отдельные field-компоненты и `FormData`.
- gRPC API использует protobuf messages и generated-style stub/servicer bindings вместо JSON generic handlers.
- Технические задания разведены по назначению ГОСТ 34.201 и ГОСТ 34.602.
- UI/UX exercises содержат локальные редактируемые boards и честно отделяют подготовленные материалы от внешнего evidence.
- GitHub Actions проверяет основные программные направления и документацию.
