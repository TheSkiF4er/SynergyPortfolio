# External Deliverables

Некоторые критерии учебных заданий невозможно достоверно подтвердить только файлами в Git. Репозиторий не содержит фиктивных screenshots, ссылок или результатов исследований.

| Область | В репозитории | Что требуется снаружи |
|---|---|---|
| Networking / GNS3 | адресные планы, Cisco configs, verification commands | запустить легальный IOS в GNS3, сохранить проект, screenshots/captures и реальные результаты |
| UI/UX testing | hypotheses, scenarios, forms, result templates | провести тестирование с реальными участниками и сохранить обезличенные результаты |
| Google Forms | готовая структура брифа | создать форму в аккаунте и добавить URL |
| Figma | SVG/HTML boards, tokens, handoff specs | собрать/импортировать проект, настроить Prototype/Dev Mode и добавить URL |
| Video presentation | сценарий и структура защиты | записать реальную презентацию и добавить URL |
| Git hosting | local remote/clone/branch demo | создать требуемые GitHub/Bitbucket repositories в личных аккаунтах |

Локальные детали UI/UX дополнительно описаны в `assignments/design/ui-ux/EXTERNAL_DELIVERABLES.md`.
