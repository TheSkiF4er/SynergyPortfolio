# Figma import / Developer handoff checklist

1. Создать pages: `00 Cover`, `01 Research`, `02 Wireframes`, `03 UI`, `04 Components`, `05 Prototype`, `06 Handoff`.
2. Импортировать SVG из практик 1–6 и финального кейса.
3. Создать local variables: colors, spacing, radius, typography.
4. Превратить Button/Input/Card/Nav в components + variants.
5. Настроить Auto Layout и constraints.
6. Собрать desktop/tablet/mobile frames.
7. В Prototype связать основной сценарий start workout.
8. Проверить focus/error/disabled states в specs.
9. В Dev Mode проверить размеры, tokens, export assets и naming.
10. Скопировать реальный Figma URL в `HANDOFF.md` и `EXTERNAL_DELIVERABLES.md`.
