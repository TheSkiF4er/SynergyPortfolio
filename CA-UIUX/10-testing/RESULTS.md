# Анализ результатов

Этот файл намеренно не содержит вымышленных респондентов. После проведения A/B и corridor testing:

1. заполнить `real-results-template.csv`;
2. посчитать completion rate по вариантам;
3. сравнить median time, errors и help requests;
4. выписать повторяющиеся качественные наблюдения;
5. выбрать вариант не только по скорости, но и по ошибкам/пониманию;
6. указать размер выборки и ограничение статистической значимости.

**Статус:** requires real participants.
