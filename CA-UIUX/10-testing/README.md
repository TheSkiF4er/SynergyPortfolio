# Практика 10 — A/B и corridor testing

Тест-план готов, но **реальный эксперимент считается завершённым только после участия реальных людей**. `test-plan.csv` больше не выдаётся за фактические результаты: он содержит сценарий/варианты. `real-results-template.csv` предназначен для внесения наблюдений после проведения сессий, а `RESULTS.md` описывает способ анализа.
