# Практика 3 — типографика

`typography.svg` показывает три шрифтовые пары и выбранную итоговую систему. Для переносимости используются web/system-safe аналоги:

1. **A — Arial + Georgia**: нейтральная UI-база + выразительные editorial accents.
2. **B — Trebuchet MS + Georgia**: более дружелюбный характер, но слабее плотная интерфейсная работа.
3. **C — Arial only**: самый устойчивый и доступный вариант для продукта 60+.

Выбран вариант C. Styles: Display 52/60/700, H1 40/48/700, H2 28/36/700, Subheader 20/28/600, Body 18/28/400, Caption 14/20/400. Основной пользовательский текст не уменьшается ниже 16 px.
