# Google Form blueprint

**Название:** CHANGEBODY — клиентский бриф

1. Компания / продукт — Short answer — required
2. Контактное лицо — Short answer — required
3. Какую бизнес-задачу должен решить продукт? — Paragraph — required
4. Приоритетная аудитория — Checkboxes: начинающие / 60+ / восстановление / опытные / другое
5. Главный пользовательский сценарий — Paragraph — required
6. Какие метрики должны измениться? — Checkboxes: conversion / completion / retention / support load / NPS-CSAT / другое
7. Поддерживаемые платформы — Checkboxes: desktop / tablet / mobile web / iOS / Android
8. Есть ли брендбук/design system? — Multiple choice: да / частично / нет
9. Обязательные accessibility/legal ограничения — Paragraph
10. Сроки и критерии приёмки — Paragraph — required
11. Ссылки на существующий продукт/аналитику — Paragraph

Confirmation text: «Спасибо. Ответы используются только для проектирования учебного кейса и не публикуются с персональными данными без согласия».
