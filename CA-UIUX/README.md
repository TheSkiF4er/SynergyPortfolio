# CA-UIUX — промежуточные практические задания

13 практических частей оформлены как единый case-study workflow. В качестве базовой темы используется сервис тренировок **CHANGEBODY**, чтобы артефакты логично продолжали финальный `CA-DSGN1`.

Артефакты созданы в открытых форматах HTML/SVG/Markdown. Для пунктов, где методичка требует Figma/Google Forms/видеозащиту, добавлены готовая структура и материалы для переноса, но фиктивные внешние URL не создаются.
