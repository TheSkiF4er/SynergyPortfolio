# React 02 — настройка окружения

Практическая работа выполнена в формате, указанном в задании: структура **Create React App** (`react-scripts`) и подключение внешних npm-пакетов.

Используются:
- `dayjs` — форматирование даты и времени;
- `nanoid` — генерация короткого идентификатора.

```bash
npm install
npm start
npm run build
```

> Create React App сейчас считается устаревшим инструментом для новых production-проектов, однако здесь он сохранён намеренно для буквального соответствия учебному заданию.
