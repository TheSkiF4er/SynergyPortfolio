# Тема 7 — Наследование

`Employee(name, lastname, number)` и `ProductionWorker(shiftNumber, payment)`; CLI запрашивает все пять значений и выводит через геттеры. Проверяются корректность имени, номера, смены и ставки.

## Запуск из корня SynergyPortfolio

```bash
make -C assignments/programming/java-fundamentals compile
java -cp assignments/programming/java-fundamentals/.build javafundamentals.inheritance.Main 
```

## Проверка

```bash
make -C assignments/programming/java-fundamentals test
```

Все тесты курса выполняются без внешних библиотек на JDK 21+.
