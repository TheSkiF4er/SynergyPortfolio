# Тема 3 — Массивы и циклы

Выполнены все четыре основные задачи и повышенная сложность: минимум нечётных для двух массивов, разложение трёхзначного числа, треугольник из 8 высотой 10, 5-летний прогноз вклада, длина самой длинной **подряд идущей** последовательности одинаковых элементов. Выберите `minimum`, `expand`, `triangle`, `deposit`, `longest-run`.

## Запуск из корня SynergyPortfolio

```bash
make -C assignments/programming/java-fundamentals compile
java -cp assignments/programming/java-fundamentals/.build javafundamentals.arrays.Main minimum
```

## Проверка

```bash
make -C assignments/programming/java-fundamentals test
```

Все тесты курса выполняются без внешних библиотек на JDK 21+.
