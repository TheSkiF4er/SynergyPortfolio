# Тема 4 — Основы ООП

Класс `Card` с характеристиками карты, конструктором и `getCardInfo()`. Каждое поле снабжено объяснением выбранного типа. Показаны **исключительно вымышленные реквизиты**, не используйте класс для реальной банковской информации.

## Запуск из корня SynergyPortfolio

```bash
make -C assignments/programming/java-fundamentals compile
java -cp assignments/programming/java-fundamentals/.build javafundamentals.oopbasics.Card 
```

## Проверка

```bash
make -C assignments/programming/java-fundamentals test
```

Все тесты курса выполняются без внешних библиотек на JDK 21+.
