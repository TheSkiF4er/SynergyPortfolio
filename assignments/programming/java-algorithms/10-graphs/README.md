# 10 — Алгоритмы для деревьев и графов

Решение соответствует четырём объектам из методички:

1. исходный ориентированный граф хранится в коде как двумерная матрица смежности (`task1Matrix()`);
2. для исходной матрицы `P1…P8` создан `matrix-graph.svg`;
3. второй исходный граф хранится как список смежности (`task3AdjacencyList()`);
4. для заданного списка `[0]→[1][2], [1]→[2][3], [2]→[1], [3]→[2]` создан `list-graph.svg`.

SVG являются редактируемыми графическими результатами. В тексте критериев есть противоречие про «только матрицы», но само задание №3 явно требует список смежности, поэтому реализованы обе требуемые формы.
