# ООП

ООП организует программу вокруг объектов с состоянием и поведением. В отличие от процедурного подхода, данные и операции над ними группируются в классы/объекты. Класс задаёт структуру и методы экземпляров; конструктор инициализирует экземпляр.

Задание реализовано в `index.html`: `Employee` с четырьмя свойствами и методом расчёта зарплаты, а также `Employee1` с методами получения/изменения каждого свойства и проверкой достаточности данных.
