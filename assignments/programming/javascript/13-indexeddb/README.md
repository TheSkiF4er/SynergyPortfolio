# IndexedDB

IndexedDB — асинхронная транзакционная object-store база данных в браузере. Она подходит для значительных объёмов структурированных данных и offline-first приложений.

**Зачем локальное хранилище:** кэш, offline-mode, черновики, очереди синхронизации, клиентские индексы.

**IndexedDB vs LocalStorage:** IndexedDB асинхронен, транзакционен, хранит объекты/индексы и подходит для больших наборов. LocalStorage синхронен, хранит только строки и удобен лишь для малого объёма простых настроек.

`index.html` реализует добавление и чтение записей.
