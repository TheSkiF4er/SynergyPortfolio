# Деструктуризация

Деструктуризация — синтаксис извлечения значений из массивов и свойств объектов в переменные. Деструктурировать можно iterable-массивы/строки и объекты. Сама операция не изменяет исходный объект, хотя полученные ссылочные значения продолжают указывать на те же вложенные объекты. Практика: параметры функций, React props, ответы API, значения по умолчанию, rest-элементы и обмен значений.

`index.mjs` содержит пример вложенной деструктуризации.
