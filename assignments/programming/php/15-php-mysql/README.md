# 15 — PHP + MySQL

`index.php` принимает дату, подключается к MySQL через PDO и выводит каждый заказ отдельным блоком. Ошибки соединения и запроса перехватываются отдельно; пользователю показывается безопасное сообщение, диагностический код записывается в лог PHP.

Используется схема из `../14-database-schema/schema.sql`.
