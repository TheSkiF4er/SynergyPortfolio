# 16 — Объектно-ориентированное программирование

Работа объединяет все 9 подпунктов методички в один небольшой пример:

- класс пользователя и наследование;
- `private`/`protected` свойства и контролируемый доступ;
- абстрактный родитель с 5 свойствами и 2 абстрактными методами;
- magic methods `__get`, `__set`, `__call`, `__clone`;
- случайный возраст при создании объекта;
- namespace `UserSystem` (`User`, `Authentication`, `Roles`, `Permissions`);
- trait `ActiveStatus`;
- `serialize()` / `unserialize()` в локальные файлы;
- пользовательское исключение и `try/catch/finally`.

```bash
php demo.php
```
