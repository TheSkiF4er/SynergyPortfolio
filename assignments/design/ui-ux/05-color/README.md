# Практика 5 — цвет в Web

Три **одинаковых по структуре** экрана позволяют сравнивать только влияние цвета, не смешивая его с изменением layout:

- `palette-blue.svg` — спокойный синий: доверие/технологичность;
- `palette-coral.svg` — тёплый коралловый: энергичность/lifestyle;
- `palette-green.svg` — зелёный: здоровье/спокойствие.

Для финального направления выбран зелёный вариант: он поддерживает health-позиционирование и сохраняет достаточный контраст primary CTA. Перед production используется автоматическая WCAG-проверка конкретных пар text/background.
