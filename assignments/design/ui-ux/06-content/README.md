# Практика 6 — работа с контентом

Подготовлены три визуальных направления одного блока:

- `photo-style.svg` — photo-led композиция с безопасной зоной, caption/credit и правилами кадрирования;
- `illustration-style.svg` — собственная векторная иллюстрация, редактируемая после импорта в Figma;
- `icon-style.svg` — набор UI-иконок с единым stroke/размером.

## Photo source для финальной подстановки

Для буквальной сдачи с реальной фотографией выбран лицензируемый reference: Wikimedia Commons, **“Home workouts.jpg”**, автор Freddy Kabeya, CC BY-SA 4.0. В Git-архив намеренно не копируется внешний бинарный файл без сетевой загрузки; при подготовке Figma его нужно скачать с Wikimedia Commons и указать attribution/licence. Это лучше, чем коммитить случайное изображение без подтверждённой лицензии.

Правила: meaningful image получает alt/caption; декоративный asset — пустой alt; иконки 24×24, stroke 2 px, rounded caps/joins; фото не содержит текст, критичный для сценария.
