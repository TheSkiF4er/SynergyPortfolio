# Практика 4 — текст в интерфейсе

`interface-copy.svg` — экран 1920×1080, построенный на выбранной типографике. Copy rules: действие называется глаголом, label не заменяется placeholder, ошибка содержит способ исправления, подтверждение сообщает результат и следующий шаг. На одном экране представлены normal, validation и success states.
