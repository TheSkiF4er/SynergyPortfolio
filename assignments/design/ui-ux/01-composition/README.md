# Практика 1 — композиция

`composition.svg` — законченный A4-макет (210×297 mm, портрет), а не абстрактная схема. В нём применены визуальная иерархия, правило близости, выравнивание, контраст, свободное пространство и один доминирующий CTA. Макет можно импортировать в Figma/Illustrator и экспортировать в PDF для сдачи.

Проверка: заголовок считывается первым, затем benefit/описание, затем CTA; вторичный блок визуально отделён, но остаётся в общей оси композиции.
