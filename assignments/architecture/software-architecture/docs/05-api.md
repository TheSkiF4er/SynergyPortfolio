# ДЗ 5 — Интерфейсы программирования приложений

В `../api/` реализованы три транспорта над одной in-memory моделью Product из **10 полей**: REST/FastAPI, GraphQL и gRPC. Каждый вариант содержит операции создания, получения по ID, фильтрованного списка, редактирования и удаления. Инструкции запуска находятся в `api/README.md`.
