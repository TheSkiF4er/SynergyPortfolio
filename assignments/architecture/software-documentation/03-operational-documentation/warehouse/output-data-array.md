# Массив выходных данных — АС «Склад»

## Общие сведения
Выходные данные формируются по запросу пользователя либо регламентному заданию. Основные формы представления: экранная таблица, CSV/XLSX для обработки и PDF для печатного представления. Доступ к набору данных ограничивается ролью пользователя.

| Код | Наименование | Форма | Реквизиты |
| --- | --- | --- | --- |
| stock_balance_report | Ведомость складских остатков | CSV/PDF/экран | warehouse_id, sku, product_name, unit, quantity, reserved, available, report_at |
| movement_register | Реестр движений | CSV/PDF | document_no, occurred_at, movement_type, warehouse, sku, quantity, operator |
| deficit_report | Отчёт о дефиците | CSV/экран | sku, product_name, warehouse, quantity, min_stock, shortage |

## Требования к формированию
1. В отчёте фиксируется дата/время формирования и применённые фильтры.
2. Денежные значения выводятся с двумя знаками после запятой; количества — с точностью, заданной единицей измерения.
3. Даты представляются в формате `DD.MM.YYYY`, машинный экспорт может использовать ISO 8601.
4. Пустое значение не подменяется нулём, если это меняет смысл показателя.
5. Экспорт должен использовать кодировку UTF-8.
6. Пользователь не получает поля, запрещённые его ролью.

## Хранение
Сформированные файлы не являются первичным источником данных. При необходимости повторного использования отчёт формируется заново из актуальной БД; временные файлы удаляются согласно политике хранения.
