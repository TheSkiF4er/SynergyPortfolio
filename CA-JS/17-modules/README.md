# Модули JavaScript

Модули позволяют разделять код, явно описывать зависимости, повторно использовать функции и избегать глобального namespace. Современные evergreen-браузеры поддерживают ES modules; для старых браузеров используется сборка/transpilation.

`.mjs` явно обозначает ES module в средах, где расширение/`package.json` участвуют в выборе module system. **export** публикует binding из модуля, **import** подключает его. В браузере модули запускаются через `<script type="module">`. ES modules автоматически работают в strict mode; директива `"use strict"` включает строгий режим для classic script/function и запрещает часть опасных неявных конструкций.

`index.mjs` импортирует функцию из общего модуля.
