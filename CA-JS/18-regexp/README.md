# Регулярные выражения

Регулярное выражение — шаблон для поиска/проверки/замены текста. Практические задачи: валидация формата, поиск токенов, parsing ограниченных текстовых шаблонов, массовые замены. В JS доступны литералы `/pattern/flags` и конструктор `new RegExp(pattern, flags)`. `RegExp()` особенно полезен, когда паттерн строится динамически из строки.

`index.mjs` извлекает email-адреса.
