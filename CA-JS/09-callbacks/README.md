# Асинхронность и callback-функции

Асинхронность позволяет не блокировать основной поток JavaScript во время ожидания таймера, сети или ввода/вывода. Callback — функция, передаваемая другой функции для вызова после события/завершения операции.

`index.html` подключает `style.css`, а `app.js` динамически загружает `post.js` через callback. Ошибка загрузки отображается пользователю.
