# JSON

1. **Зачем нужен JSON:** это компактный текстовый формат обмена структурированными данными между приложениями, API, браузером и сервером; удобен также для конфигураций и хранения.
2. **Какие данные представляет:** объекты, массивы, строки, числа, `true`, `false`, `null` и их вложенные комбинации.
3. **Структура:** объект — пары `"ключ": значение`, массив — упорядоченный список значений. Ключи объекта всегда строки в двойных кавычках.
4. **Можно ли представить любой набор данных:** нет. В JSON напрямую нет `undefined`, `BigInt`, функций, `Symbol`, `Date`, `Map`, `Set`, циклических ссылок и бинарных данных. Их необходимо преобразовывать.
5. **Практические задачи:** REST API, экспорт/импорт настроек, web storage, конфигурации, обмен данными frontend/backend.

`index.mjs` показывает сериализацию и обратный разбор.
