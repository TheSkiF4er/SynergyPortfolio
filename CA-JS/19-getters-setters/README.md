# Getters / Setters

Свойства-аксессоры выглядят для вызывающего кода как обычные свойства, но чтение вызывает `get`, а запись — `set`. Они позволяют вычислять значение, нормализовать/валидировать присваивание, поддерживать совместимый публичный API и скрывать внутреннее представление.

`index.mjs` демонстрирует аксессоры `celsius`/`fahrenheit` с проверкой входного значения.
