# Cookies

Cookies — небольшие пары данных, которые браузер хранит для origin и может отправлять серверу в HTTP-заголовке `Cookie` согласно атрибутам. Применяются для session identifiers, предпочтений и некоторых сценариев аналитики. Чувствительные session cookies должны обычно иметь `HttpOnly`, `Secure`, подходящий `SameSite` и ограниченный срок. `index.html` создаёт учебную cookie на один год.
