# CA-JS — Стек технологий JavaScript

20 домашних заданий курса. Каждая папка содержит `README.md` и исполняемый пример. Общие алгоритмические решения экспортируются из `solutions.mjs` и покрыты `node:test`.

```bash
node --test tests/*.test.mjs
```

Browser API-задания (`cookies`, `IndexedDB`, dynamic script loading) запускаются открытием соответствующего `index.html` через локальный HTTP-server.
