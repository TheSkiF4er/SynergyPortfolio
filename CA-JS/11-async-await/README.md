# async / await

- `async` заставляет функцию всегда возвращать Promise.
- `await` приостанавливает выполнение **этой async-функции** до settled-состояния Promise, не блокируя event loop.
- Практические задачи: последовательные HTTP-запросы, ожидание файлов/таймеров, удобная обработка ошибок через `try/catch`, orchestration асинхронных операций.
- **Синтаксический сахар** — более удобная запись уже существующей семантики. `async/await` построены поверх Promise и не создают отдельную модель асинхронности.

В `index.html` есть небольшой запускаемый пример.
