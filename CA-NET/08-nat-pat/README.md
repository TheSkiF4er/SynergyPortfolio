# Тема 8 — NAT/PAT

R1 выполняет PAT для `192.168.1.0/24` через внешний адрес `1.1.1.1`; R5=`1.1.1.5`. После Telnet с нескольких внутренних клиентов проверить `show ip nat translations` и увидеть разные translated TCP ports. Без PAT R5 не имеет маршрута обратно в приватную сеть, поэтому TCP-сессия не устанавливается.
