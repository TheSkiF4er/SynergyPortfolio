# CA-NET — Компьютерные системы и сетевые технологии

Решения лабораторных тем 3–12. В каждой папке находятся:

- `README.md` — алгоритм выполнения и команды проверки;
- `configs/` — готовые Cisco IOS-конфигурации;
- при необходимости — таблица адресации.

**GNS3:** бинарные Cisco IOS images не входят в репозиторий. Создайте устройства с интерфейсами, указанными в README, и примените конфиги через консоль. Это делает решения воспроизводимыми без распространения лицензируемых образов.

Учебные credentials в лабораториях Telnet: `student / synergy`, enable secret: `lab-enable`.
