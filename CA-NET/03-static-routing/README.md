# Тема 3 — статическая маршрутизация

Топология: `R1 — R2 — R3`, а также `R2 — R4`.

| Link | Network | Addresses |
|---|---|---|
| R1–R2 | `192.168.12.0/24` | `.1`, `.2` |
| R2–R3 | `192.168.23.0/24` | `.2`, `.3` |
| R2–R4 | `192.168.24.0/24` | `.2`, `.4` |

После применения `configs/*.cfg` проверить `show ip interface brief`, `show ip route static`, затем с R1: `ping 192.168.23.3` и `ping 192.168.24.4`.
