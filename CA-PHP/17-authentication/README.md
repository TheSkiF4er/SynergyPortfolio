# 17 — Идентификация, аутентификация и авторизация

Реализованы MySQL-таблица пользователей, безопасный hash пароля, форма входа, публичная и приватная страницы и защита прямого URL приватной страницы через session check.

## Подготовка

1. Выполнить `schema.sql` в MySQL.
2. Задать `DB_*` переменные окружения.
3. Создать тестового пользователя: `php seed.php admin Strong!123 "Admin User"`.
4. Запустить `php -S 127.0.0.1:8080 -t .` и открыть `/index.php`.

Пароли хранятся только через `password_hash()`. SQL выполняется prepared statements.
