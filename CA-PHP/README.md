# CA-PHP — Язык программирования PHP

17 учебных работ курса PHP. Решения рассчитаны на PHP **8.4+** и сгруппированы по темам методички.

| № | Каталог | Тема |
|---:|---|---|
| 01 | `01-html-basics` | HTML/CSS, семантическая разметка |
| 02 | `02-php-html` | PHP внутри HTML, массивы, таблица |
| 03 | `03-syntax` | Синтаксис, строки, арифметика |
| 04 | `04-operators` | Составные операторы, variable variables |
| 05 | `05-predicates` | Предикаты и логические функции |
| 06 | `06-conditionals` | Четверть часа, сезон, квадрат/куб, перестановка цифр |
| 07 | `07-loops-arrays` | Циклы и многомерные массивы |
| 08 | `08-functions` | Пользовательские и стандартные функции |
| 09 | `09-strings` | `substr`, `chunk_split`, `strpos`, `strrchr` |
| 10 | `10-dates` | Даты и интервалы |
| 11 | `11-output-buffering` | Буферизация вывода и callback |
| 12 | `12-forms` | Обработка формы из четырёх полей |
| 13 | `13-validation` | Серверная валидация регистрации |
| 14 | `14-database-schema` | MySQL-схема интернет-магазина и JOIN |
| 15 | `15-php-mysql` | PDO + выбор заказов по дате + обработка ошибок |
| 16 | `16-oop` | ООП, наследование, magic methods, namespace, trait, serialization, exceptions |
| 17 | `17-authentication` | Хеширование паролей, session auth, public/private pages |

## Проверка

```bash
make -C CA-PHP test
```

Команда выполняет `php -l` для всех PHP-файлов и запускает локальные unit/smoke-проверки функций, не требующих MySQL.

Работы 14, 15 и 17 используют MySQL. Параметры подключения передаются через `DB_HOST`, `DB_PORT`, `DB_NAME`, `DB_USER`, `DB_PASSWORD`.

Исходные PDF методички в репозиторий не включены.
