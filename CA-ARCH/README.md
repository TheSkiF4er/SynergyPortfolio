# CA-ARCH — Принципы проектирования и развития архитектуры ПО

Единая предметная область для всех домашних заданий: **MarketHub**, marketplace цифровых продуктов. Последовательное использование одного проекта делает решения согласованными: выбор технологий → C4/UML/ER → frontend → API → patterns → ТЗ → SDLC → итоговая архитектура.

Диаграммы хранятся в Mermaid/PlantUML-тексте и рендерятся GitHub либо локальными инструментами.
