# Статус учебных заданий

Обозначения репозитория:

- `CS*` — учебная практика;
- `CA-*` — учебные задания.

## Покрытие архива практических заданий

| Дисциплина | Выполнено в репозитории | Статус |
|---|---|---|
| Архитектуры операционных систем | `CA-OS`: 8 заданий | ✅ код и smoke-тесты |
| Компьютерные системы и сетевые технологии | `CA-NET`: лабораторные 3–12 | ✅ конфигурации/топологии/проверки; GNS3 собирается локально |
| Стек технологий JavaScript | `CA-JS`: 20 заданий | ✅ исходники, browser demos, tests |
| React | `CA-REACT`: 9 заданий | ✅ 9 отдельных приложений |
| Итоговый React-проект | `CA-JSTS1`, `PLUS`, `MAX` | ✅ |
| UI/UX — промежуточные практики | `CA-UIUX`: 13 практических частей | ✅ локальные артефакты; внешние ссылки требуют аккаунта владельца |
| UI/UX — финальный проект | `CA-DSGN1*`, `CA-DSGN2*` | ✅ оба варианта выполнены |
| Архитектура ПО | `CA-ARCH`: 8 ДЗ + итоговый проект | ✅ документы, диаграммы, APIs, patterns |

## Внешние действия перед формальной сдачей

Некоторые критерии нельзя достоверно выполнить простым созданием файла в Git-архиве:

1. **GNS3.** Конфигурации и адресные планы готовы, но Cisco IOS image не распространяется. Нужно импортировать легальный образ, собрать топологию, применить конфиги и при необходимости сохранить локальный `.gns3`/screenshots.
2. **Figma.** SVG/HTML/дизайн-материалы готовы. Если проверка требует именно Figma URL, нужно импортировать/собрать экраны в личном аккаунте и вставить реальную ссылку.
3. **Google Forms.** Шаблон брифа подготовлен; форму нужно создать в аккаунте владельца и вставить URL.
4. **Видеозащита.** Сценарий подготовлен; запись должен сделать автор и добавить ссылку.

Репозиторий намеренно не содержит вымышленных ссылок, поддельных скриншотов, проприетарных Cisco-образов или исходных методических PDF.
