# Evidence checklist — внешние действия

Этот файл предназначен только для фиксации **реально выполненных** действий. Фиктивные ссылки и скриншоты не добавляются.

- [ ] GitHub: создать/указать настоящий URL репозитория.
- [ ] Bitbucket: создать/указать настоящий URL репозитория.
- [x] Локально зафиксировать `git remote -v` — см. `local-git-transcript.txt`.
- [x] Локально выполнить успешный `git clone` — см. transcript.
- [x] Локально создать новую ветвь — см. transcript.
- [ ] При необходимости приложить собственные скриншоты интерфейса GitHub/Bitbucket.

После выполнения внешних действий этот checklist можно отметить и добавить реальные URL.
