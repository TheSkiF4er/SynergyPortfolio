# Тема 6 — Технические задания на разработку ИС

Подготовлены пять самостоятельных технических заданий:

1. ИС «Кадры»;
2. ИС «Склад»;
3. ИС «Бухгалтерия»;
4. ИС «Клиенты»;
5. ИС «Абитуриенты».

Каждое ТЗ содержит общие сведения, назначение и цели, характеристику объекта автоматизации, функциональные и нефункциональные требования, состав работ, порядок контроля/приёмки, подготовку объекта, требования к документации и источники разработки. Требования снабжены идентификаторами и проверяемыми критериями.
