# Каталог базы данных — АС «Поставщики»

## Назначение
Каталог фиксирует логическую структуру основной реляционной базы данных АС «Поставщики». Типы приведены как рекомендуемые SQL-типы; физическая схема может уточняться при проектировании.

| Таблица | Назначение | Ключевые атрибуты |
| --- | --- | --- |
| suppliers | Поставщики | id PK; name varchar(255); tax_id varchar(32); status varchar(20); rating decimal(3,2) |
| supplier_contacts | Контакты | id PK; supplier_id FK; person varchar(120); phone varchar(32); email varchar(255) |
| supply_contracts | Договоры | id PK; supplier_id FK; number varchar(64); signed_at date; valid_until date; amount decimal(16,2); status varchar(20) |
| deliveries | Поставки | id PK; supplier_id FK; contract_id FK; delivery_date date; amount decimal(16,2); status varchar(20) |
| supplier_ratings | Оценки | id PK; supplier_id FK; delivery_id FK; quality int; timeliness int; comment text; created_at timestamp |

## Правила целостности
- каждый первичный ключ `id` уникален и не изменяется после создания;
- внешние ключи должны ссылаться только на существующие активные/исторические записи согласно бизнес-правилам;
- денежные и количественные значения хранятся в `decimal`, а не `float`;
- даты операций сохраняются отдельно от системного времени создания записи, если эти значения различаются;
- удаление значимых бизнес-объектов выполняется логически либо ограничивается при наличии зависимостей;
- изменения критичных сущностей журналируются.

## Связи
- `supplier_contacts` содержит внешние ключи, связывающие запись с родительскими сущностями предметной области.
- `supply_contracts` содержит внешние ключи, связывающие запись с родительскими сущностями предметной области.
- `deliveries` содержит внешние ключи, связывающие запись с родительскими сущностями предметной области.
- `supplier_ratings` содержит внешние ключи, связывающие запись с родительскими сущностями предметной области.

## Резервирование и доступ
База данных резервируется по регламенту организации. Прямой доступ конечных пользователей к СУБД запрещён; работа выполняется через прикладной API. Учётная запись приложения имеет только необходимые права.
