# Состав выходных данных — АС «Склад»

Документ определяет реквизитный состав основных выходных сообщений. Поля формируются серверной частью из согласованных сущностей БД; вычисляемые показатели рассчитываются до экспорта.

| 4 | `unit` | строка | По данным | Реквизит выходного сообщения |

## Общие требования контроля
- идентификаторы и даты должны соответствовать источнику данных;
- агрегаты сверяются с детальными строками;
- сортировка и фильтры указываются в заголовке отчёта;
- повторное формирование с одинаковым срезом данных должно давать одинаковый результат;
- ошибки формирования регистрируются в техническом журнале без раскрытия чувствительных данных пользователю.
