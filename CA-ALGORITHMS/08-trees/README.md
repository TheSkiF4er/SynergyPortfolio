# 08 — Деревья

BST поддерживает `insert/search/delete`, включая замену удаляемого узла с двумя потомками минимальным узлом правого поддерева. Средняя сложность — `O(log n)`, худшая у несбалансированного BST — `O(n)`.

Во втором задании формулировка требует `название книги → номер полки`, а пример показывает `номер → название`. Поэтому присутствуют оба варианта: `getBookAndNumber()` следует тексту задания, `sortedByShelf()` воспроизводит пример.
