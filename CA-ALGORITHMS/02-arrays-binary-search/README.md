# 02 — Массивы и бинарный поиск

- Пара с заданной разностью в отсортированном массиве реализована двумя указателями за `O(n)`. Требование `O(log n)` из методички в общем случае недостижимо без дополнительных ограничений.
- Поиск строки — классический `O(log n)` binary search.
- Ближайшая меньшая перестановка цифр реализована без перебора всех перестановок.
