# CA-ALGORITHMS — Углублённые структуры и алгоритмы

10 домашних работ и итоговый Java-проект. Код рассчитан на **JDK 21+**, не требует Maven/Gradle и сторонних библиотек.

| № | Каталог | Тема |
|---:|---|---|
| 01 | `01-linear-search-big-o` | линейные алгоритмы и Big O |
| 02 | `02-arrays-binary-search` | массивы и бинарный поиск |
| 03 | `03-linked-lists-selection-sort` | связный список, selection sort |
| 04 | `04-recursion-stack` | рекурсия и стек |
| 05 | `05-call-stack-quick-sort` | рекурсивные задачи, quick sort |
| 06 | `06-queues` | очереди FIFO |
| 07 | `07-hash` | HashMap и частоты |
| 08 | `08-trees` | Binary Search Tree |
| 09 | `09-algorithm-tasks` | кругляши цифр, Fibonacci |
| 10 | `10-graphs` | матрица/список смежности + SVG-графы |
| — | `final-project` | JSON → static array → quick sort → binary search → map → JSON |

## Проверка

```bash
make -C CA-ALGORITHMS test
```

Все алгоритмические реализации собственные там, где это требуется заданием. README в спорных местах указывает фактическую, а не ошибочно заявленную в методичке, асимптотику.
