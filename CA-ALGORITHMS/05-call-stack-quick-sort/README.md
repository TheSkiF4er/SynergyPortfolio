# 05 — Стек вызовов и quick sort

`printReverseDigits()` использует только рекурсию, целочисленную арифметику и вывод в `PrintStream` — без строк, списков, массивов и циклов в самом алгоритме. Палиндром проверяется рекурсивно без циклов. `FootballTeam` содержит `teamName` и `goalCountBySeason`; `randomTeams()` создаёт 10 команд, а собственный quick sort сортирует их по голам по возрастанию.
