# CA-OS — Архитектуры операционных систем

Восемь практических заданий: Bash, файловый ввод/вывод, Unix/TCP sockets, процессы, zombie process и POSIX threads.

```bash
make
make test
```

Все примеры предназначены для Linux/macOS (POSIX). Zombie-process демонстрация рассчитана на Linux и завершается самостоятельно.
